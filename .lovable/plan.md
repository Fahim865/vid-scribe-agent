# ReelPilot — Full Backend Setup (Lovable Cloud + নিজের API key যেকোনো সময়)

তোমার উত্তর অনুযায়ী: সম্পূর্ণ ব্যাকএন্ড, ইমেইল লগইন, আর **BYOK** — যেকোনো প্রোভাইডারের API key তুমি নিজে জমা দেবে, যেকোনো সময় অ্যাপ সেই key দিয়েই কাজ করবে (নিজের key = কোটার বাইরে)।

## ধাপ ১ — Lovable Cloud + লগইন

- Lovable Cloud চালু: ডাটাবেস, অথ, স্টোরেজ একসাথে সেট হবে
- ইমেইল+পাসওয়ার্ড লগইন চালু (`enable_email_auth`), সাথে:
  - `/auth` পেজ: Sign in / Sign up / Forgot password
  - `/reset-password` পেজ (ইমেইল লিংক থেকে নতুন পাসওয়ার্ড সেট)
- `profiles` টেবিল (Account পেজে প্রোফাইল দেখানোর জন্য), সাইনআপে অটো-ক্রিয়েট ট্রিগার
- সব এক্সিস্টিং পেজ (Dashboard, Create, Settings, Providers, Connections, Schedule, Calendar, Library, Account) `_authenticated` লেআউটের নিচে যাবে — লগইন ছাড়া ঢুকলে `/auth`-এ রিডাইরেক্ট

## ধাপ ২ — ডাটাবেস (সব টেবিলে RLS: প্রত্যেকে নিজের ডেটাই দেখবে)

- `agent_settings` — niche, tone, frequency, time slots, mode, autopilot on/off
- `platform_connections` — প্ল্যাটফর্ম কানেকশন (কাস্টম প্ল্যাটফর্মসহ), স্ট্যাটাস
- `provider_keys` — তোমার জমা দেওয়া API key, **সার্ভারে এনক্রিপ্টেড** থাকবে; ফ্রন্টএন্ডে কখনো আসল key ফেরত যাবে না (শুধু মাস্কড দেখা যাবে, যেমন `sk-••••1234`)
- `videos` — জেনারেট করা কনটেন্ট (script, scenes, status, thumbnail)
- `scheduled_posts` — সিডিউল কিউ, pending/published/failed, retry count
- `notifications`, `usage_log` — কোন key দিয়ে কত ব্যবহার

## ধাপ ৩ — BYOK: যেকোনো API যেকোনো সময়

- Providers পেজ থেকে জমা দেওয়া key সার্ভার-সাইডে এনক্রিপ্ট হয়ে সেভ হবে; টেস্ট-কানেকশন বাটন এবার সত্যিকারের API কল করে valid/invalid দেখাবে
- Script/LLM: তোমার key থাকলে সেটা (OpenAI-compatible হলে custom endpoint-ও চলবে), না থাকলে Lovable-এর বিল্ট-ইন AI — তাই key ছাড়াও সব কাজ করবে
- Voice (TTS), ইমেজ/ভিজ্যুয়াল, ভিডিও-জেনারেশন ক্যাটাগরিতেও একই নিয়ম — প্রতিটা ধাপে কোন key চলছে সেটা সার্ভার ঠিক করে আর usage_log লিখবে
- key সবসময় সার্ভার-সাইডে থেকে ব্যবহার হবে, ব্রাউজারে কখনো যাবে না

## ধাপ ৪ — সত্যিকারের জেনারেশন ফ্লো

- `/create` ফ্লো সত্যি AI দিয়ে চলবে: Brief → Script (LLM) → Scenes → Voice (TTS) → Captions → ফাইনাল রিল
- ভিডিও রেন্ডারিং সার্ভারে ভারী কাজ — এই ধাপে দুইটা পথ: (ক) তোমার নিজের ভিডিও-জেনারেশন key (Runway/Luma ইত্যাদি) দিলে সেই API, (খ) নাহলে ইমেজ+ভয়েস+ক্যাপশন দিয়ে বানানো স্লাইড-স্টাইল রিল (9:16, স্টোরেজে সেভ)
- জেনারেট হওয়া ফাইল Lovable Cloud Storage-এ থাকবে; Library পেজ সত্যি ডেটা দেখাবে

## ধাপ ৫ — Scheduler ও পোস্টিং

- `pg_cron` প্রতিদিন/নির্দিষ্ট সময়ে সার্ভারে চলবে: নতুন স্ক্রিপ্ট+ভিডিও জেনারেট → কিউতে পোস্ট পাঠাবে; fail হলে অটো-রিট্রাই, notification দেবে
- ক্রন-এন্ডপয়েন্ট `/api/public/*`-এ, সিক্রেট ভেরিফিকেশন সহ
- **সোশ্যাল অটো-পোস্টিংয়ের বাস্তবতা:** TikTok/Instagram/YouTube/Facebook-এ সত্যিকারের অটো-পোস্ট করতে প্রতিটা প্ল্যাটফর্মের নিজস্ব ডেভেলপার অ্যাপ, অ্যাপ্রুভাল ও OAuth দরকার — এগুলো তোমার নিজের ডেভেলপার অ্যাকাউন্ট থেকে করতে হবে। এই ধাপে কানেকশন স্টোরেজ ও ফ্লো রেডি থাকবে; তুমি ডেভেলপার অ্যাপ দিলেই পোস্টিং লাইভ হবে। ততদিন "Review" মোডে ভিডিও ডাউনলোড করে নিজে পোস্ট করতে পারবে।

## ধাপ ৬ — ফ্রন্টএন্ড সংযুক্তি

- `store.tsx`-এর localStorage স্টেট সত্যি ডাটাবেসে রিপ্লেস: সব পেজ server functions দিয়ে পড়বে/লিখবে, সেভ করলে টোস্ট
- Notifications সত্যি ঘটনা থেকে আসবে; Dashboard analytics ডাটাবেস থেকে
- শেষে সব ফ্লো লগইন করে এন্ড-টু-এন্ড ব্রাউজারে যাচাই

## টেকনিক্যাল নোট

- সব সার্ভার লজিক `createServerFn` + `requireSupabaseAuth`; ক্রন/ওয়েবহুক সার্ভার রুটে
- এনক্রিপশনের জন্য সার্ভার সিক্রেট (generated secret) — কোডে কখনো হার্ডকোড না
- ডেমো ডেটা মাইগ্রেশনে seed হবে, পেজ-লোডে না
- ফ্রন্টএন্ডের ডিজাইন (ডার্ক গ্লাসমরফিজম, ভায়োলেট-পিংক) অপরিবর্তিত থাকবে
