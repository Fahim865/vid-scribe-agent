# Content Muse

আমার জন্য একটা AI-powered content creation agent website বানাও, নাম "___" (তোমার নাম বসাবে)।

মূল কনসেপ্ট: এটা শুধু একটা টুল না, একটা autonomous agent — যে প্রতিদিন নিজে থেকে

ভিডিও/রিল কন্টেন্ট AI দিয়ে জেনারেট করবে এবং সিডিউল অনুযায়ী আমার সোশ্যাল মিডিয়া

অ্যাকাউন্টে (YouTube Shorts, Instagram Reels, TikTok, Facebook) নিজে থেকে পোস্ট করে দেবে।

Features দরকার:

1. Dashboard — যেখানে আমি analytics দেখতে পারবো (views, engagement, follower growth),

   আপকামিং সিডিউলড পোস্ট, এবং আগের জেনারেট করা সব ভিডিওর লিস্ট।

2. Agent Settings — এখানে আমি সেট করবো: niche/topic, posting frequency (দিনে কতবার),

   কোন কোন প্ল্যাটফর্মে পোস্ট হবে, brand tone/voice, এবং "Full Auto" বা

   "Review Before Post" মোড বাছাই করার অপশন।

3. Content Generation flow — টপিক/ব্রিফ দিলে AI স্ক্রিপ্ট লিখবে, সিন-বাই-সিন ব্রেকডাউন

   করবে, প্রতিটা সিনের জন্য video clip জেনারেট করবে, TTS ভয়েসওভার যোগ করবে,

   caption/subtitle বার্ন করবে, এবং সব ক্লিপ স্টিচ করে ফাইনাল রিল এক্সপোর্ট করবে (9:16)।

4. Scheduling engine — ব্যাকগ্রাউন্ডে অটোমেটিক প্রতিদিন নতুন কন্টেন্ট জেনারেট করবে

   ও নির্ধারিত সময়ে পাবলিশ করবে, ফেইল হলে রিট্রাই করবে।

5. Social connections page — OAuth দিয়ে প্রতিটা প্ল্যাটফর্ম কানেক্ট/ডিসকানেক্ট করার UI,

   কানেকশন স্ট্যাটাস দেখানো।

6. Content calendar view — কোন দিন কী পোস্ট হয়েছে/হবে তার ক্যালেন্ডার।

ডিজাইন স্টাইল: ডার্ক থিম, গ্লাসমরফিজম, ভায়োলেট-পিংক গ্রেডিয়েন্ট অ্যাকসেন্ট

(আমার আগের mockup "AutoVid Studio"-এর স্টাইল অনুসরণ করে)।

এখনকার জন্য ফ্রন্টএন্ড UI/UX পুরোপুরি ফাংশনাল বানাও (dummy/sample data দিয়ে),

পরে ব্যাকএন্ড API যোগ করবো।
